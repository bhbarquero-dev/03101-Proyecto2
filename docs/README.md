# Documentación

Material de apoyo para el documento técnico (diagramas, capturas, borradores).

Secciones requeridas del documento técnico:

1. Portada
2. Introducción y descripción del problema
3. URL del vídeo explicativo (5–10 min, rostro visible)
4. URL del repositorio
5. Manual de usuario
6. Justificación técnica con fuentes (≥ 3 decisiones, IEEE, ≥ enero 2022)
   - Incluye la pregunta de análisis de gestión de datos (≥ 300 palabras, ≥ 2 fuentes, alternativa descartada)
7. Conclusiones y limitaciones
8. Referencias bibliográficas (IEEE, ≥ 3, ≥ enero 2022)
